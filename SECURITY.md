# Security reports

Do not put vulnerabilities, credentials or customer data in public issues. Use the repository's GitHub private vulnerability reporting when enabled; otherwise request a private reporting channel from the repository owner without publishing exploit details.
No production security certification is claimed by this foundation. Only the reviewed development branch is in scope.
Security invariants: docs/security/SECURITY-INVARIANTS.md. Threat register: docs/security/THREAT-MODEL.md.
Rotate and revoke any exposed credential immediately through its owner, preserving redacted evidence. Do not print it in logs or handoffs.
