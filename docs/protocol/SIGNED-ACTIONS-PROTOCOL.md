# Signed actions — design only

Not implemented or certified in Foundation V1. A later protocol must bind canonical versioned action bytes, audience, operation, resource, nonce, expiry and user intent to a fresh server challenge; display the exact action before verification and prevent replay atomically.
Ordinary login or a notification is not transaction authorization. Specify canonical encoding, downgrade resistance, cross-device trust and independent test vectors before code. Use established cryptography; AI cannot approve.
