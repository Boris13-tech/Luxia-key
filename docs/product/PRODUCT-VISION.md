# Product vision

LUXIA Key proves identity, device presence and user intent. LUXIA Identity governs enterprise identities and access. Key remains usable independently; enterprise policy administration is not a Key responsibility.
The Google AI Studio implementation is LUXIA Key Personal — UX Baseline V1. UI affordances express intent, not implemented or certified capability.
This foundation supports new pseudonymous passkey identities and server sessions in a development API. It does not establish civil identity, prove a particular physical device for synced passkeys, or certify transaction intent.
